# श्री साई गणेश मंडळ - बाप्पाचे आगमन (Ganpati Festival Invitation)

A high-performance, interactive digital invitation webpage for **Shri Sai Ganesh Mandal (श्री साई गणेश मंडळ)**, featuring devotional animations, royal envelope opening effect, audio player, 3D family/committee carousel, interactive timeline with modal, flower shower physics simulation, and Google Maps integration.

---

## ✨ Features

- 📯 **Royal Envelope & Curtain Opening**: Interactive gold wax seal with smooth sliding curtain animation.
- 🎵 **Devotional Audio Player**: Background music with smooth fade-in/fade-out and floating controls.
- 🔔 **Temple Bells**: Interactive swinging bells with synthesized Web Audio API chime sound.
- 🌸 **Flower Shower Engine**: Physics-based 3D petal trajectory animation ("फुलांची वर्षाव करा").
- 📅 **Interactive Timeline & Modal**: Detailed schedule of events from Sthapana to Visarjan.
- 👨‍👩‍👦 **3D Member Carousel**: Swipeable and clickable 3D card slider.
- 📍 **Location & Google Maps**: Embedded map with one-click navigation.
- 📱 **Fully Responsive**: Optimized for all devices and mobile browsers.

---

## 🛠️ Built With

- **HTML5** & **CSS3** (Custom Animations & Responsive Layouts)
- **Vanilla JavaScript** (No external framework dependencies)
- **Web Audio API** & **Web Animations API**
- **Google Fonts** (Noto Serif Devanagari, Yatra One, Asar, Poppins)

---

## 🚀 Getting Started

Simply open `index.html` in any web browser, or serve it locally:

```bash
# Using Python
python -m http.server 3000

# Using Node.js npx serve
npx serve .
```
